# Sigma Workforce Measurement & Scale Standard

Sigma workforce size is an **audited capability measure**, not a generated-name count.

## Executive chain
Mitesh (Root Authority) -> Sigma Governor -> Directors -> Masters -> Specialists -> bounded temporary specialists.

## Headcount rule
Every unique `agent_id` counts at most once regardless of how many councils or files reference it. Four headline counters must always be shown separately: **Registered**, **Operational**, **Certified/Black Belt**, and **Active Mission**. Runtime status requires runtime evidence.

## Daily evolution
The Agent Factory Controller and Evaluation & Evolution Controller run a capability-gap cycle: taxonomy gaps and mission failures create recruitment candidates; candidates are deduplicated, given a curriculum and benchmark, independently evaluated, then registered/promoted only when they add measurable capability. Low-value duplicates are rejected or consolidated.

## Scale targets
1,000 -> broad coverage; 10,000 -> deep specialisation; 100,000 -> fine-grained cross-domain specialisation; 1,000,000 -> permitted only when automated registry/routing/evaluation/observability demonstrates that quality does not degrade.

## Dashboard
The Sigma Mesh visual control plane must expose live counters, organisation graph, coverage heatmap, growth curve, certification, current missions, agent drill-down, knowledge freshness, benchmark history and recruitment gaps.

## Quality
Growth is subordinate to accuracy, evidence, security and task success. No target date justifies lowering certification gates.
